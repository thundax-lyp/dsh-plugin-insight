## 办公与运营

### [InvoiceFlowAI — DSH 发票整理插件](20261019T074011Z-smoke-invoice.md)

研究深度：源码级。

- **用途：**从邮箱集中收集发票，识别、归档并生成报销准备报表。
- **亮点：**把原先分散的下载、分类和 Excel 汇总串起来，对固定邮箱、重复批量任务有潜在价值。
- **关键质疑：**为省整理时间引入 Python、OCR、Chromium 和模型处理，配置、纠错及人工核验会不会把收益吃回去？它产出准备材料，不能据此认定报销已办结。
- **建议：**已有 DSH、收票频繁且愿意核验的用户可用小批脱敏材料试验；偶发收票者先比较人工与桌面版。

## 软件交付

### [TaskSwarm — 并行开发任务编排](20261019T074011Z-smoke-taskswarm.md)

研究深度：源码级。

- **用途：**把能拆开的开发任务按依赖分波，在 Git worktree 中并行执行，再评审和集成。
- **亮点：**把任务包、隔离工作区、调度和串行合并组织成可观察流程，适合已有测试标准的独立任务。
- **关键质疑：**多 Agent 省下的等待，能否覆盖拆任务、模型评审、冲突处理与最终验收？当前 npm 入口不可用，评审分支也未保证“明确 PASS 才放行”。
- **建议：**目前继续观察；分发与宿主兼容确认后，在可丢弃仓库里试，保留最终人工验收。

### [dsh-project-memory](20261019T074011Z-smoke-memory.md)

研究深度：源码级。

- **用途：**在项目内保留任务、文件关联、文档／符号索引和经验，帮助新会话恢复工作。
- **亮点：**默认读到再索引，召回附来源；确定性索引不用模型调用，能从较小范围试起。
- **关键质疑：**多保存、多召回是否真的减少恢复时间与错误？目录所说“零成本”没有覆盖默认嵌入表、提示占用、噪声治理和跨作用域经验维护。
- **建议：**本轮优先试用候选：同一项目经常换会话、已有明确任务验收的人，可先做单项目对照；尚不能作为安装推荐。
