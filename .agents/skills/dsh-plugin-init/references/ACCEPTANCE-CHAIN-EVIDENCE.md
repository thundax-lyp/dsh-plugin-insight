## 拒绝与事务边界

隔离验证覆盖以下情形，未将合成研究或观察写入项目。

- 缺少一题决定、决定摘要不匹配、漏核真实补充材料，提交被拒绝。
- 可以保存明确revise决定，但不能暂存。
- 交付报告在预检查后改变，旧决定不能继续使用。
- 在stageRecords锁内记录核对处主动拒绝，未保存部分WORK检查点；之后仍能完成原批次。
- 整批重复stage保持幂等；CLI输出文件已存在时，在执行阶段写入前拒绝。

两份真实历史稿另外用于复查语义边界。model-everything旧稿行号合法但引用了不支持重构说明的段落；OpenWrite旧稿准确披露了未解包Core的高影响缺口，需要补查后收窄质疑与假设。机械逐题校验均可通过，因此父Agent语义验收和关键依赖补查必须保留。该复查已知历史修订，不属于盲测，不报告检出率。

## 验证限制

本次是固定交付的重放，不是重新研究或独立模型A/B。接口成功、页面相同与决定覆盖完整，不能证明原报告每个判断正确、换用其他worker仍同质量，或TOKEN已经减少某个百分比。

项目不维护上述临时验证脚本或合成testcase。长期入口复用现有校验器和stage-batch事务；当前档案、观察／检查点及生成一致性由`npm run check`检查。检查结果为本地结果，不代表远端CI。
