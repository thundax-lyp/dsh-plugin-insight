# 效果与总成本

研究问题：完成一个合格任务是否更有效，代价和不适用条件是什么？

本题先完成独立论证，再参与综合 INSIGHT；共同证据要求见[研究规范](RESEARCH-STANDARD.md)。

### 成本与收益比较

以同一类“合格任务”为计量单位，先定义验收标准和工作负载。现金支出与人工时间分别记录，
未说明人工单价时不能把小时与金额直接相加。区分首次部署／配置、日常使用和升级／迁移成本。

现金成本包括实际适用的模型／API、服务订阅、计算、存储和网络；任务成本包括失败尝试、重试、
人工复核与修正，不仅统计一次调用或成功样本的 token。固定费用须注明评估周期、任务量和分摊方法。
可计算“同批次总现金支出 ÷ 合格交付数”，同时报告合格率和人工时间；没有合格交付时不输出有限单位成本。
没有实测时使用有来源的估算，列明价格日期、币种、模型、调用量假设和遗漏项，不编造 ROI 或收益比例。

### 按阶段交付

分别分析首次使用、持续使用与失败恢复的投入；升级、迁移和退出按实际适用情况补充。每阶段分开列现金/资源与人工/时间，未知量注明缺什么数据；失败恢复应计入重试、排查、部分完成状态的核对或重建。采用[输出标准](../../dsh-plugin-init/references/OUTPUT-STANDARD.md#成本与效果的表格展示)的成本表与效果表呈现，完整回答保留计量单位、机制、条件及证据，不从表格齐全推断收益已验证。
