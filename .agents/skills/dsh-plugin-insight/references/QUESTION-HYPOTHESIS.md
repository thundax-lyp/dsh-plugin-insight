# 新假设与验证

研究问题：由贡献、反例和缺口可推导什么新方向，如何支持或推翻它？

本题先完成独立论证，再参与综合 INSIGHT；共同证据要求见[研究规范](RESEARCH-STANDARD.md)。

### 从供给缺口到机会验证

某类条目少或不存在，只能说明当前来源中的供给情况。提出“值得做”的机会时，检查：

- 是否有具体用户反复遇到同类问题，场景、频率、严重程度及受影响人群是什么。
- 现有替代方案的实际代价在哪里，用户如何绕过问题，是否有真实使用或解决尝试。
- Issue、使用反馈、修复记录和实际任务是否相互支持，反馈是否独立、是否可能重复或偏样本。
- 最小方案如何改善可观察结果，其成功判据、成本边界和可能推翻机会判断的证据是什么。

把需求证据、供给证据和商业意愿分别判断；抱怨不等于愿意迁移或付费。
缺少需求或结果验证时称为机会假设，列出缺失证据和最小验证，不升级为已确认市场机会。

## 推导方法

从已核查事实明确推导步骤，尝试机制推广、组合、替换或业务流程重组；说明相对已有方案的增量、依赖和新增负担。列出最小可执行验证、成功标准与否定条件。未得到实际证据前保持假设状态；无新假设时解释原因，不能强凑创新。
