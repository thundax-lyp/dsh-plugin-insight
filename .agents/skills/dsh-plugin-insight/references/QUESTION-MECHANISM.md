# 功能与机制

研究问题：能力如何从入口、注册、调用、数据流和状态变化中实现？

本题先完成独立论证，再参与综合 INSIGHT；共同证据要求见[研究规范](RESEARCH-STANDARD.md)。

## 核查方法

从固定版本入口跟踪注册、配置、主调用链、数据边界和持久化；核对宿主API、可选分支和失败路径。以作者说明提出能力主张，用具体源码检验其实现，不能把静态定义当作运行可用性。必要时参照工程核查问题中的AST候选与人工确认。

## 回答要求

给出输入到输出的完整链路、关键机制及其条件；逐项定位材料，区分作者声称、源码可见和运行未知。指出动态注册、模型或外部服务等尚未确认环节。
